# `analysis-helpers`

This is a simple Python package meant to accompany the data analysis code in 🚨[ContextLab/memory-dynamics](https://github.com/ContextLab/memory-dynamics)🚨. It provides the `Episode` and `Participant` classes for loading and accessing the data, various functions and constants used across multiple notebooks (to ensure consistency and reduce boilerplate), and a few utilities for displaying code and data within the notebooks.

If you want to replicate any of the analyses or figures from the paper (or just
play around with the code), build the Docker environment following the
instructions in the
🚨[main README](https://github.com/ContextLab/memory-dynamics/blob/master/README.md)🚨,
and the `analysis_helpers` package will be installed automatically inside the container.
